🚌 Sistema de Pagamentos de Ônibus

Projeto desenvolvido em Python com o objetivo de praticar e aplicar conceitos fundamentais de lógica de programação.

O sistema simula um gerenciamento simples de pagamentos de ônibus, permitindo ao usuário realizar diferentes operações por meio de um menu interativo.

⚙️ Funcionalidades

O sistema permite:

Registrar um novo pagamento
Exibir todos os registros realizados
Buscar um registro específico
Atualizar um registro existente
Remover um registro
Sair do sistema
🧠 Conceitos utilizados

Durante o desenvolvimento, foram aplicados conceitos fundamentais de Python e lógica de programação, incluindo:

-while
-for
-if, elif e else
-Funções
-Listas
-Dicionários
-Entrada e saída de dados
-Manipulação de registros
-Estruturas de repetição e controle de fluxo
🎯 Objetivo

O principal objetivo deste projeto é praticar os fundamentos da programação em Python, desenvolvendo a capacidade de criar um sistema simples com operações de cadastro, consulta, atualização e remoção de dados.

Este projeto faz parte do meu processo de aprendizado e evolução na programação.
